# 國高中盃　預賽至決賽　選手可搜尋明細

115年全國國高中盃個人羽球錦標賽（2026/10/20–10/31，高雄市亞柏會舘）的選手賽程查詢網頁。
輸入姓名或隊名，即可看到該選手從資格賽第一場到預計決賽的每一場：日期、時間、場地、對手與結果，並串接主辦方的即時戰況。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `國高中盃_預賽至決賽_選手可搜尋明細.html` | 網頁本體（賽程資料已內嵌，單一檔案） |
| `live_server.py` | 伺服器：提供網頁、代為讀取即時戰況、統計上線人數（只用 Python 標準函式庫，不需安裝套件） |
| `render.yaml` | Render 雲端部署設定 |

## 功能

- **搜尋與篩選**：姓名（雙打可搜任一人）、學校／隊名、學制、競賽項目、比賽日期（預設「全部日期」），可一鍵清除。每頁 30 筆，可直接輸入頁數跳頁。未設定條件時顯示首戰時間並依首場排序；設定任一條件後顯示下一場時間並依下一場排序（已淘汰者排在最後）；選日期時只列出當天有比賽的選手（已在該日期之前淘汰者不列出），當天場次以黃底標示。
- **選手卡片**：收合時顯示首戰時間（設定搜尋條件後改顯示「下一場」比賽時間，已淘汰顯示「已淘汰」）、預計決賽時間（需一路全勝）與「接下來三場」比賽時間（依實際賽況更新，略過輪空，假設持續獲勝）；點開顯示完整晉級路線。對手未定時顯示「勝者 #N 之間（X 人可能）」，可展開名單；名單會隨比賽結果更新，已淘汰的選手會從名單中移除，只剩一人時直接顯示姓名並標示「已確定」。
- **即時戰況**：每 3 分鐘自動同步，也可按「立即更新」。自動帶入勝負、每局比分、進行中、棄權、雙棄、已淘汰，並同步最新的日期、時間、場地。
- **頁首**：已完賽／雙棄場數、目前上線人數、「開啟官方即時成績」、「即時分數」與「YouTube 頻道直播」連結。
- **場次編號**：`Q#` 為資格賽，`#` 為會內賽，須搭配組別辨識。

## 運作方式

```
瀏覽器 ──(每 3 分鐘)──> /proxy ──> 主辦方 proxy_st.php（結果暫存 8 秒）
        ──(每 30 秒)───> /ping  ──> 回報心跳、取回上線人數
```

- 主辦方的資料介面沒有開放跨網域讀取，所以網頁不能直接連它，必須經由 `live_server.py` 轉送。
- 轉送時需帶瀏覽器等級的標頭，否則會被對方回應 403。
- 即時資料以「選手姓名」對應賽程表中的選手，場次以「組別＋場次號」對應。
- 上線人數：75 秒內有回報的瀏覽器才計入；只存匿名隨機代碼於記憶體，不記錄 IP；頁面在前景才會回報。服務重啟後歸零，約一分鐘內恢復。

## 本機執行

```
python live_server.py
```

- 電腦：http://localhost:8765
- 手機（同一個 Wi-Fi）：視窗會印出網址，例如 http://192.168.x.x:8765
- Windows 防火牆跳出視窗時請按「允許存取」。

## 部署到 Render（免費方案）

1. 把本資料夾的三個檔案上傳到 GitHub repository 的**根目錄**。
2. Render → New → Blueprint → 選該 repository → Apply。
3. 完成後取得 `https://<服務名稱>.onrender.com`，電腦與手機都能開。

**更新網頁**：重新上傳同名檔案並 Commit，Render 會自動重新部署，網址不變。
**避免休眠**：免費方案閒置約 15 分鐘會休眠。可用 UptimeRobot 或 Better Stack 每 5 分鐘訪問一次網址。
**比賽結束後**：刪除保活監控與 Render 服務。

## 已知限制

- 比分、棄權與雙棄的顯示，開賽前只用模擬資料測過，尚未以真實比賽資料驗證；開賽後請與主辦方即時頁核對。
- 「哪一方棄權」是依棄權欄位開頭的 A／B 判斷；若實際格式不同，只會顯示「棄權」，勝負不受影響。
- 若即時資料中的姓名寫法與賽程表不同，該場勝負將無法帶入。
- 賽程資料來自 1005 版賽程表，並已套用之後的 52 場時間異動；主辦方再調整時，以最新公告與現場叫號為準。賽程表內容變動需重新產生網頁。
- 網頁中的「資料來源網址」已隱藏，僅為畫面上不顯示，並非安全機制。

## 疑難排解

| 現象 | 可能原因 |
|---|---|
| 「無法直接讀取即時戰況」且顯示 403／502 | 主辦方伺服器拒絕了代理請求，請查看畫面顯示的完整訊息 |
| 上線人數一直顯示「—」 | 直接開啟 HTML 檔，或 `live_server.py` 不是新版 |
| 第一次開啟要等很久 | Render 免費方案休眠後喚醒，約 30–60 秒 |
| 即時成績沒有更新 | 確認「每3分鐘自動更新」已勾選，或按「立即更新」 |
